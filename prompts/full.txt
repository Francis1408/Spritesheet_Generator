RULES
- Use only this sprite sheet. Never use RPG conventions to fill gaps.
- The sheet may contain fewer than four usable views. Analyze only the views
  present; never reconstruct a missing view and never treat its features as absent.
- A feature visible in only ONE view is still valid evidence. Say which view.
- Never invent features. Small details count even in simplified/chibi art.
- Describe appearance before naming an object. Prefer "gold material extending
  from the shoulders down the back" over "golden cloak" when the type is unclear.
- The uniform mid-gray background around the character is the image background,
  not part of the character. Never report it as skin, clothing, or armor. Only
  gray that lies inside the character outline is character material.

rest poorly:

- whether an item seen from two angles is the SAME object
- garment continuity: does one material run from torso to legs with no break?
- weapons, shields, and large accessories, including how they are held

visibility

  NOT_VISIBLE  = relevant, but no available view exposes it.

evidence_quality

SILHOUETTE — shape words only, never "male" or "female": torso width, shoulder
width vs hip width, waist narrowing, chest outline curved or flat, and overall
proportions (stocky / slender / broad / elongated).

ANATOMY — literal, never a species name: ears, horns, wings, tails, tusks,
scales, fur, extra limbs, other unusual anatomy. Multi-view sheets reveal these
better than crops, so check the back and sides specifically.

SKIN COLOR — blue, green, purple, red, gray, white, or black can all be skin.

- PALE / WHITE / CREAM: state whether a boundary separates the pale region from

  the same tone continues unbroken across exposed anatomy.

BODY vs LOWER — keep them separate even when one continuous material covers both.
Describe the torso-and-arms portion under "body" and the legs-and-feet portion
under "lower", and note in the evidence field if it is clearly one garment.
